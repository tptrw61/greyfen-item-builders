Reconciliation report · weapons, shields, and armor · generated 2026-08-09

Detailed gap report — exactly why each unmatched item could not be built →
Every weapon, shield, and piece of armor/barding with game stats in the Greyfen catalogue was rebuilt with the Utopia item builders (weapon / chest / head / hand / foot / shield). Each build below was produced by driving the real builder code, so every JSON file loads straight back into its builder and each HTML file is that builder's own summary card. Every item name links back to its Greyfen catalogue entry (↗ catalogue).

How items were sorted: ■ Exact match — the builder reproduces every mechanical stat (attack actions, damage, range, hands / defenses, block, dodge, slots); only descriptive flavor is left out. JSON + HTML saved.  ·  ▲ Reasonably sure — the core stat line is reproduced exactly, but the item carries a rule the generic builder has no switch for (a ▲ caveat). JSON + HTML saved.  ·  ■ Can't fully match — a defining property can't be represented at all (a ■ blocker); the closest build is still saved, with JSON + HTML except for animal barding, which is JSON only.  ·  Not compatible — no stat line to build; nothing saved.

Note on rarity & cost: the builder derives rarity and Value (sp) from Refinement Points, so they frequently differ from the catalogue's editorial rarity and price. As requested, both are shown for reference (orange = differs, green = same) but were not used to decide a category. Builder values follow the Greyfen house rule that doubles item SP, so they are twice what the base Utopia builders would report for the same build.
